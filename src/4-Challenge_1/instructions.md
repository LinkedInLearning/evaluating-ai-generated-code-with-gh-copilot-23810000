# Challenge 1: Find and Fix the Problem

## The task

The program in `exercise.py` was generated by GitHub Copilot from the
prompt in `prompt.md`. It's supposed to split a restaurant bill among a
group of friends, including tax and tip, and tell each person exactly
what they owe.

Here's the reasonably expected behaviour: **when you add up what every
person pays, it should equal the actual total bill exactly (bill + tax + tip).**

The program should also behave reasonably when someone mistypes a
number.

## Your job

Work through the loop yourself:

1. **Inspect** the code. Read it before running anything.
2. **Test** it. Try a few different combinations of bill amount, tax,
   tip, and number of people. Try at least one case where the total
   doesn't divide evenly among the group.
3. **Verify** the result against the requirement above. Does the total
   collected actually match the bill? Does the program handle bad input
   without crashing?
4. **Improve** it. Write down what you'd change to fix what you found. Implement the fix either by modifying the code yourself, or by asking GitHub Copilot to fix it for you. Remember to be clear in your prompts.

## Before looking at our solution

Make a short note describing:
- What input exposed the problem
- Why the code produces that result
- What you'd change to fix it

There are two separate issues to find here, one is the main one this
challenge is built around, the other is a smaller bonus catch. You don't
need to find both to get value out of this, but see if you can, or even better, see if you can find more problems with this program!

When you're done, open `solution.md` and compare notes. It's fine if
your wording is different, what matters is whether you found the right
issue and can explain why it's a problem.
