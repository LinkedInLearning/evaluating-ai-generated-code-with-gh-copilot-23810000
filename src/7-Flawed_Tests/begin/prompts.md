Write a small Python program for an online shop that calculates a customer's
shipping quote. Orders totaling $50 or more receive free shipping; smaller
orders pay a $6.99 standard shipping charge. Include a function that accepts
items as name-and-price pairs and returns the subtotal, shipping charge, and
final total. Use only the Python standard library.

Also include a unittest suite covering orders of different amounts and a
final-total calculation to expose any faults in the function.
