# Challenge 2: Run the Full Cycle

## The task

Build a small Python program that parses CSV data.

At minimum, it should let someone:
- Pass in CSV text or a CSV file
- Handle fields that contain commas, quotes, and empty values
- Preserve the distinction between an empty field and a missing field
- Read rows correctly even when a field contains a newline inside quotes
- Show the parsed result clearly, such as rows of data or a printed table

That's it. Turn this into your own prompt for
GitHub Copilot. There's no required wording, 
this is meant to be your own request.

## What to do with what you get

Run the full loop yourself:

1. **Generate** the code with Copilot.
2. **Inspect** it before running anything.
3. **Test** it with more than one kind of input, including something
   you wouldn't expect a "normal" user to type.
4. **Verify** the result actually matches what you asked for above.
5. **Improve** it if you find something worth fixing, then check your
   fix.

There's no planted bug this time. You might generate something clean on
the first try, and that's a perfectly good outcome, the point of this
exercise is running the process, not necessarily finding something
broken.

When you're done, open `checklist.md` and go through it. It covers
everything this course has looked at. There's no fixed answer to compare
against, since your code and prompt won't match anyone else's. Use the
checklist to make sure you actually worked through each step rather than
stopping as soon as the code looked fine.
